# 桥梁概况

本桥为三跨预应力混凝土连续箱梁桥，全长 248 米，宽 16.5 米，建成于 2011 年。

# 构件编号

- 支座编号自北向南依次为 ZZ-01 至 ZZ-12。
- 伸缩缝编号自北向南依次为 SS-01 至 SS-04。

# 病害记录

| 构件 | 病害类型 | 位置 |
| ZZ-03 | 支座脱空 | 北边跨 |
| ZZ-07 | 支座剪切变形 | 中跨 |
| SS-02 | 伸缩缝止水带破损 | 北边跨 |

# 病害成因

- ZZ-03 支座脱空由垫石标高偏差引起。
- ZZ-07 支座剪切变形由温度变化引起。
- SS-02 止水带破损由杂物堆积引起。
