# 产品定位

OrbitSync 是面向团队的文档同步与协作工具，支持私有部署。

# 版本信息

| 版本 | 发布时间 | 状态 |
| 3.0 | 2025-05-06 | 已停服 |
| 3.1 | 2025-11-18 | 维护中 |
| 3.2 | 2026-04-22 | 当前版本 |

# 3.2 新功能

- 支持离线编辑与自动冲突合并。
- 支持细粒度权限到文件夹级别。
- 支持全文检索中文分词。

# 性能参数

| 指标 | 数值 |
| 单库容量 | 500GB |
| 单文件上限 | 2GB |
| 并发连接 | 800 |

# 兼容性

- 服务端支持 Linux 与 Windows Server。
- 客户端支持 Windows、macOS 与 Android。
- 不再支持 Windows 7 客户端。

# 已知问题

- 大文件首次同步较慢。
- 离线冲突合并暂不支持表格文件。
