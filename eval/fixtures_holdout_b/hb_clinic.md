# 目的

本规程用于规范体检中心样本采集、检测与报告发放流程。

# 岗位职责

- 中心主任负责质量管理与报告终审。
- 采样护士负责样本采集与标识核对。
- 检验技师负责仪器操作与结果录入。
- 报告审核员负责结果复核与报告签发。

# 责任划分

- 试剂采购由器械科负责。
- 样本留存由样本库负责。
- 医疗废物处置由院感科负责。

# 检测项目

体检中心开展项目包括：血常规、尿常规、肝功能、肾功能、血脂四项、心电图、胸部正位片。

# 样本流程

- 登记 → 采样 → 离心 → 检测 → 复核 → 签发。

# 质量要求

- 空腹采血要求禁食 8 小时以上。
- 尿常规样本需在 2 小时内送检。
- 血脂四项需空腹采血。
