# 产品概述

LF 系列裂缝观测仪用于混凝土结构表面裂缝宽度的现场测量，基础量程为 0-10mm。

# 型号命名规则

型号中 LF 之后的第一位数字表示放大倍率等级，第二位数字表示是否带数据存储功能，
其中 0 表示不带存储，1 表示带存储。
因此 LF-20 表示 2 级放大、不带存储；LF-21 表示 2 级放大、带数据存储。

# 主要技术参数

| 参数 | 数值 |
| 量程 | 0-10mm |
| 分辨率 | 0.01mm |
| 工作温度 | -10℃ ~ 50℃ |
| 供电 | 2 节 AA 电池 |
| 整机重量 | 320g |

# 与 LF-30 的差异

LF-30 的放大倍率为 3 级，分辨率提高到 0.005mm，但整机重量增加到 480g，
且不提供数据存储版本。
