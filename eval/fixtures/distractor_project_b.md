# 工程概况

本工程位于宁波市高新区，总建筑面积约 12 万平方米，地下三层。
基坑开挖深度约 14.2 米，围护结构采用地下连续墙加三道混凝土支撑。

# 监测项目

监测项目包括：地下连续墙墙顶水平位移、墙顶竖向位移、墙身测斜、支撑轴力、坑外地下水位、周边管线沉降。

# 观测点布设

在基坑周边布设测点 16 个，点号 GC1-GC16，间距 15 米。
竖向位移测点点号 SW1-SW12。支撑轴力监测组点号 ZL1-ZL12。

# 监测人员

本项目监测人员包括：项目负责人 1 名（刘洋），监测组长 1 名（周涛），现场观测员 3 名（孙磊、吴迪、郑凯），数据审核员 1 名（冯雪）。

# 监测设备

| 设备名称 | 规格型号 | 数量 | 产地 |
| 全站仪 | 拓普康GM-101 | 2台 | 日本 |
| 电子水准仪 | 徕卡DNA03 | 1台 | 瑞士 |
| 测斜仪 | CX-70 | 3台 | 中国 |

# 测量精度要求

全站仪测角精度为 ±2″。
电子水准仪每公里往返测高差中数偶然中误差不超过 0.3mm。
水准仪检定有效期至 2027 年 1 月 20 日。

# 监测频率

| 施工阶段 | 监测频率 |
| 开挖深度小于 5 米 | 1次/2d |
| 开挖深度大于 5 米 | 1次/1d |
| 底板浇筑完成后 | 1次/3d |
| 结构完工后 | 1次/7d |

# 预警值

地下连续墙墙顶水平位移累计预警值为 40mm，变化速率预警值为 4mm/d。
