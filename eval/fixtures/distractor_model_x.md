# 产品定位

Flux-Image-Pro 是面向商业设计的图像生成模型，主打高分辨率输出。

# 核心能力

## 高效推理

模型针对消费级显卡做了量化优化，在 4090 上单张生成耗时约 1.8 秒。

## 透明图层支持

支持输出带 alpha 通道的 PNG，便于二次合成。

## 局部编辑

支持涂抹重绘与扩图，暂不支持指令编辑。

## 写实质感

在材质与光照表现上具有较强写实风格，适合产品渲染。

# 结论

Flux-Image-Pro 定位商业设计场景，强调速度与分辨率。
