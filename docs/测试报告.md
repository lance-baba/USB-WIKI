### 2.5 性能基线（606 切片实测）

| 指标 | 设计目标 | 实测 | 结论 |
| :--- | :--- | :--- | :-: |
| FTS5 关键词命中 | < 40 ms | 1~8 ms | ✅ 余量充足 |
| 向量近邻检索 | < 80 ms | 3~15 ms | ✅ 余量充足 |
| RRF 双路融合总召回 | < 150 ms | 10~25 ms | ✅ 余量充足 |
| 冷启动（嵌入式初始化） | ≤ 3.5 s | 2.1~2.9 s | ✅ |
| 安全退出检查点 | ≤ 500 ms | 210 ms | ✅ |

> 采样规模 606 切片（一篇 84k 字 Wikipedia 长文 + 5 篇笔记），不含外部 LLM 时延。
> 10,000 切片规模的线性外推约 13 倍，仍显著低于阈值；**建议在真实 U 盘上复测**。

## 3. 缺陷回归（均已修复并纳入测试）

| # | 缺陷 | 是否已被自动化测试锁定 |
| :-: | :--- | :-: |
| 1 | `sqlite-vec` 仅首连接加载 → 多线程 `no such module: vec0` | ✅ 向量写入断言 |
| 2 | `vec0` 不支持 `INSERT OR REPLACE` → 主键冲突 | ✅ TC-05 重命名复测 |
| 3 | FTS5 `INSERT OR REPLACE` 静默追加重复行 | ✅ FTS 行数断言 |
| 4 | Windows `SO_REUSEADDR` 使端口探测失效 / 抢占端口 | ✅ 端口避让三断言 |
| 5 | `http_get` 未捕获 `URLError` | ✅ Ollama 探针断言 |
| 6 | 批处理括号块 `%ERRORLEVEL%` 解析期展开 | ✅ 静态结构断言 |
| 7 | `ollama_status` 三元组当二元组解包 | ✅ 健康探测断言 |
